БЕЗ ТЕРМИНАЛА (проще всего)
---------------------------
1. Распакуй этот архив.
2. На github.com нажми New repository, назови block-barons, нажми Create repository.
3. На странице репозитория нажми ссылку "uploading an existing file".
4. Выдели ВСЕ файлы и папку public внутри распакованной папки и перетащи в окно браузера.
5. Нажми Commit changes.

ЗАПУСК ОНЛАЙН НА RENDER (Vercel не подходит: там нет WebSocket)
----------------------------------------------------------------
1. Зайди на render.com, войди через GitHub.
2. New -> Blueprint -> выбери репозиторий block-barons -> Apply.
   (все настройки уже в render.yaml)
3. Через 2-3 минуты появится ссылка вида https://block-barons.onrender.com - это игра.

ЛОКАЛЬНЫЙ ЗАПУСК
----------------
npm install
npm start
Открой http://localhost:3000
