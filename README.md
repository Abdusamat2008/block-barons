# Block Barons

Онлайн-мультиплеерная настольная игра про крипто-ферму: майнинг на видеокартах, биржа с двумя монетами,
кредиты, аукционы, кризисы и секретные цели. Игра оригинальная: названия, цифры и оформление свои.

## Запуск
```
npm install
npm start
```
Открой http://localhost:3000 (с телефона в той же сети: http://IP_компьютера:3000).

## Правила
**Цель.** После последнего раунда считается капитал: деньги + монеты по курсу + видеокарты (по половине цены) + слоты фермы ($100 каждый) − кредиты. Выполненная секретная цель даёт ещё +$500.

**Ход.** 1) бросок двух кубиков и движение по кольцу из 24 клеток; 2) действие клетки; 3) этап рынка: торговля монетами, кредиты, очки удачи, настройка видеокарт. Затем «Завершить ход».

**Раунд.** Раунд = круг ходов всех игроков. В начале раунда курсы меняются (кубик для каждой монеты), с шансом 25% вытягивается карточка кризиса. В конце раунда идёт фаза прибыли: каждая включённая видеокарта добывает монеты, а ты платишь за электричество и проценты по кредитам.

**Монеты.** Нова — нестабильная (курс прыгает на 1–2 шага), Атлас — стабильная (на 1 шаг). 10 ступеней курса у каждой.

**Ферма.** Старт: 2 слота и одна Старт-карта. Видеокарты: Старт-карта (мощность 1, $200), Про-карта (3, $500), Квант-рига (6, $1100). Карта добывает монет столько, какова её мощность. Электричество: $20 за единицу мощности за раунд. Для каждой карты выбирается монета или режим «выкл». Слотов может быть до 6, новый слот стоит $300.

**Клетки.** Старт (+$100 при проходе), Работа (+$150), Магазин карт (скидка 20%), Аукцион (тайные ставки всех), Лотерея (билет $50), Кризис, Майнинг-рывок (внеплановая добыча без света), Разворот рынка, Расширение фермы, Счёт за свет, Удача (+1 очко), Хакеры (крадут монету), Биржевой бум, Инвестор (+$40 за карту).

**Кредиты.** $500 под 10% или $1000 под 20% (проценты каждый раунд), погашение в любой момент на этапе рынка. Не хватает денег на платёж: автоматически продаются монеты, затем карты, иначе долг растёт.

**Удача.** Очко удачи двигает курс выбранной монеты на 1 вверх или вниз (до 2 очков за ход).

**Кризисы.** Блэкаут (нет добычи), Запрет бирж, Крипто-хайп, Взлом биржи, Рост цен на энергию, Налоговая проверка, Халвинг, Волна покупок.

**Цели** (случайная секретная карточка каждому): 4 видеокарты, 12 монет, без кредитов, $2500 наличными, Квант-рига, по 4 монеты каждого вида, 3 остановки на «Работе».

## Что внутри
- Обучение при первом запуске (кнопка «Как играть» откроет его снова).
- Тренировка с ботами обязательна: после одной сыгранной партии открываются живые игроки.
- Лобби: открытые (видны в списке) и закрытые (вход по коду); число игроков, раундов и стартовые деньги задаёт создатель; можно добавить ботов до полного состава.
- Таймер на фазу: бросок и клетка по 30 секунд, рынок 75 секунд, аукцион 25 секунд. По истечении ход делается автоматически.
- Если игрок отключился, его заменяет бот; вернувшись, он снова управляет сам.

## Файлы
- `game.js` — правила, цифры и боты (все числа в начале файла), `server.js` — HTTP + WebSocket, `public/` — клиент.
- Прогресс игроков хранится в `data/profiles.json`.
- Переменные окружения: `PORT`, `TURN_MS` (время на фазу), `BOT_MS` (пауза бота).
