# Block Barons

Онлайн-мультиплеерная 3D-игра про крипторынок (оригинальная игра, не копия чужого проекта).

## Запуск
```
npm install
npm start
```
Открой http://localhost:3000 (с телефона в той же сети — http://IP_компьютера:3000).

## Как играть
- У каждого $1000 и 4 монеты: BLK, VLT, MNT, GRV. Раундов 5–15, на ход 30 секунд.
- Покупай/продавай кнопками +/−, массовые покупки двигают цену.
- В конце раунда случается рыночное событие.
- Карты: Накачка (+15%), Слив (−15%), Инсайд (узнать событие следующего раунда).
- Побеждает самый большой капитал (наличные + монеты).

## Что внутри
- Обучение при первом запуске (можно открыть снова кнопкой «Как играть»).
- Тренировка с ботами обязательна: после одной сыгранной партии открываются живые игроки.
- Лобби: открытые (видны в списке) и закрытые (вход по коду), своё число игроков, раундов и стартовый капитал, боты-заполнители.
- Если игрок отключился, его место занимает бот; при возврате он снова управляет сам.
- 3D-сцена на Three.js: башни монет растут и падают вместе с ценой.

## Файлы
- `game.js` — правила и боты, `server.js` — HTTP + WebSocket, `public/` — клиент.
- Прогресс игроков хранится в `data/profiles.json`.
- Переменные: `PORT`, `PLAN_MS`, `RESULT_MS`.
