# Block Barons

Онлайн-мультиплеерная настольная игра: поле из 40 клеток, кубики, покупка улиц, аренда, дома, Блокировка, карточки.
Оригинальная игра: названия, цены и оформление свои.

## Запуск
```
npm install
npm start
```
Открой http://localhost:3000 (с телефона в той же сети: http://IP_компьютера:3000).

## Правила
- Старт: $1500 (настраивается в лобби). Проход через СТАРТ: +$200.
- Бросай два кубика и иди по кругу. Дубль даёт ещё один бросок, три дубля подряд отправляют в Блокировку.
- Свободную улицу можно купить, на чужой платишь аренду. Вся цветовая группа у одного владельца: аренда ×2 и можно строить дома (до 4, затем отель, строить равномерно).
- Биржи и Майнинг-ферма: особая аренда. Событие и Фонд: случайные карточки. Комиссия и Налог платятся в банк, «Холодный кошелёк» отдаёт накопленный банк.
- Из Блокировки: дубль, $50, карта выхода или 3 неудачные попытки.
- Не хватает денег: дома продаются автоматически, иначе банкротство (улицы переходят кредитору).
- Конец: остался один игрок или прошло заданное число кругов, тогда побеждает наибольший капитал (деньги + улицы + дома).
- На ход даётся 45 секунд, потом ход делается автоматически.

## Что внутри
- Обучение при первом запуске (кнопка «Как играть» откроет его снова).
- Тренировка с ботами обязательна: после одной сыгранной партии открываются живые игроки.
- Лобби: открытые (видны в списке) и закрытые (вход по коду); число игроков, кругов и стартовый капитал задаёт создатель; можно добавить ботов до полного состава.
- Если игрок отключился, его заменяет бот; вернувшись, он снова управляет сам.

## Файлы
- `game.js` — правила и боты, `server.js` — HTTP + WebSocket, `public/` — клиент.
- Прогресс игроков хранится в `data/profiles.json`.
- Переменные окружения: `PORT`, `TURN_MS` (время на ход), `BOT_MS` (пауза бота).
